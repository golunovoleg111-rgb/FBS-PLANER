# FBS Planner

Браузерный планировщик поставок Wildberries: загружает актуальный FBS, продажи за 7 дней и остатки FBW; позволяет выбрать учитываемые склады; формирует редактируемый черновик заявки, XLSX и PDF.

Рабочая версия: <https://golunovoleg111-rgb.github.io/FBS-PLANER/>

## Главное поведение

- Повторный расчёт — безопасный черновик без резервирования.
- Предупреждения не блокируют работу. Пользователь может исключить строки и принять заявку своим решением.
- Физические коробки группируются по `BOX_ID`; строки одной коробки включаются и исключаются вместе.
- Принятая заявка учитывается в следующих расчётах до статуса «Выполнена» или «Отменена».
- Новинки можно искать по артикулу и добавлять всеми или выбранными размерами.
- Исходные WB-файлы и номенклатура остаются в браузере рабочего компьютера.

## Google Sheets и Drive

Локальный режим сразу работает без настройки и скачивает XLSX/PDF. Для чтения листов физического хранения и прямой загрузки файлов на Drive нужен OAuth Client ID веб-приложения Google Cloud. Разрешённые JavaScript origins должны включать адрес GitHub Pages.

В настройках уже указаны ID рабочей таблицы и папки. OAuth-токен хранится только в памяти вкладки и не записывается в репозиторий или `localStorage`.

## Разработка

```bash
pnpm install
pnpm test
pnpm build
pnpm dev
```

Публикация выполняется GitHub Actions из ветки `main`. В настройках репозитория Pages должен быть выбран источник **GitHub Actions**.
